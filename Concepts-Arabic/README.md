# مفاهيم للرسم — Mafahim Canvas

تطبيق Android مستقل باللغة العربية، أُنشئ من الصفر بعد استطلاع ثابت لحزمة Concepts المرفوعة. المشروع **ليس نسخة معدّلة من APK الأصلي ولا يدّعي استعادة مصدره**؛ بل يعيد تنفيذ مجموعة أولية من وظائف الرسم والطبقات بواجهة عربية.

## الحالة الحالية

- واجهة عربية كاملة باتجاه RTL.
- لوحة رسم بخلفية ورق وشبكة خفيفة.
- أدوات قلم، قلم رصاص، ماركر، ممحاة، وتحريك اللوحة.
- ألوان جاهزة وسماكة قابلة للتغيير.
- طبقات مستقلة: إضافة، اختيار، إظهار/إخفاء، وحذف.
- تراجع وإعادة حتى 40 خطوة.
- حفظ تلقائي محلي بصيغة ثنائية مع كتابة مؤقتة.
- تصدير SVG ومشاركته من Android.
- وضع فاتح/داكن لواجهة التطبيق.

## ما لم يُنفذ بعد

اللوحة الحالية ليست محرك Concepts الأصلي. لا يوجد بعد ضغط/ميل القلم، محرك تنعيم متقدم، تكبير/تصغير متعدد اللمس، دليل أشكال/قياس، استيراد صور، معرض متعدد المستندات، مزامنة سحابية، أو تصدير PDF/PSD/DXF. هذه ميزات مراحل لاحقة بعد تحليل REA الموثق واختبارها على أجهزة فعلية.

## البناء

يتطلب JDK 17، Android SDK 35، وGradle 8.11.1:

```bash
gradle testDebugUnitTest assembleDebug
```

ينتج APK الاختبار في:

```text
app/build/outputs/apk/debug/app-debug.apk
```

يمكن بناء APK تلقائياً عبر GitHub Actions. افتح تبويب Actions وانتظر سير العمل على الفرع `concepts-arabic-ai`؛ سيُرفع `app-debug.apk` كـ Artifact.

## التخزين والخصوصية

تُحفظ اللوحة محلياً في مساحة التطبيق الخاصة. لا توجد حسابات أو اتصال شبكي أو تحليلات أو مفاتيح خارجية في هذا الإصدار. لا يضم المستودع ملف APK الأصلي.

## بنية المشروع

- `app/src/main/java/app/mafahim/canvas/`: الواجهة، نموذج الرسم، التخزين، وتصدير SVG.
- `app/src/test/`: اختبارات هندسة الإحداثيات.
- `reverse-engineering/REA_PLAN_AR.md`: منهجية استكمال التحليل باستخدام REA.
