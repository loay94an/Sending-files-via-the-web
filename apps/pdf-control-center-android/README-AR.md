# مركز PDF الذكي — تطبيق Android مستقل

واجهة عربية RTL مستقلة مبنية على Android WebView محلياً، وتتصل بجسر Termux الموجود في هذا المستودع.

## الأقسام
لوحة متابعة، استيراد PDF، إعدادات OCR أولية، إعداد خادم نموذج محلي واكتشافه، محادثة محلية، تنفيذ أوامر Linux بعد تأكيد المستخدم، فتح Chrome، مشاركة النص إلى سياق العمل، وإرشادات GitHub.

## البناء
يتطلب JDK 17 وAndroid SDK Platform 35 وGradle 8.9:
```bash
cd apps/pdf-control-center-android
gradle --no-daemon assembleDebug
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## الربط
1. شغّل `apps/control-center/mobile-agent` في Termux على المنفذ 8765.
2. أدخل عنوان الجسر ورمز Bearer في الإعدادات.
3. شغّل خادم llama.cpp المتوافق مع OpenAI على 8080.
4. احفظ عنوان النموذج ثم اكتشف النماذج.

## حدود الإصدار الأول
- رمز الجسر في ذاكرة صفحة الواجهة فقط؛ تكامل Android Keystore ما زال مطلوباً.
- OCR يعرض خيارات أولية ولم يمررها بعد إلى محرك الاستخراج.
- مشاركة PDF تستقبل إشعار الملف، لكن الاستيراد النهائي يتم عبر منتقي الملفات داخل الواجهة.
- لا يقرأ جلسات Chrome أو ChatGPT تلقائياً.
- لا ينفذ النموذج أوامره تلقائياً.
- اكتشاف النماذج يعتمد ما يعلنه خادم النموذج، وليس مسح كل ملفات GGUF.

## الأمان
أبق الجسر على loopback فقط. لا تحفظ GitHub PAT أو رمز الجسر في المستودع. راجع أوامر الطرفية قبل التنفيذ.
