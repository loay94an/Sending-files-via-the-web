# وصلة — نقل مباشر بين الأجهزة

واجهة عربية/إنجليزية لنقل الملفات عبر WebRTC DataChannel. خادم التنسيق يمرر رسائل التفاوض فقط ولا يستقبل بايتات الملفات.

## نشر Cloudflare
- GitHub Pages لا يشغل Durable Objects؛ انشر المشروع على Cloudflare Workers.
- ثبّت Wrangler: `npm install -g wrangler`.
- من مجلد worker شغّل `wrangler login` ثم `wrangler deploy`.
- اضبط النطاق في Cloudflare. ملفات الواجهة في جذر المستودع.

## ما يتضمنه النموذج الأولي
- رابط جلسة بمعرّف عشوائي 128 بت وصلاحية 1–24 ساعة.
- طلب موافقة المستقبل، واتصال WebRTC، وSTUN فقط دون TURN.
- إرسال ملفات متعددة عبر قناة DataChannel، ومحاولة دعم عدة مستقبلين.
- واجهة RTL/LTR وPWA وسجل محلي.

## قيود معلنة
- WebRTC المباشر قد يفشل على بعض شبكات NAT والجدران النارية؛ لا يوجد TURN كمسار احتياطي.
- الاستكمال الحقيقي بعد إعادة تحميل الصفحة أو إعادة اختيار الملف غير مكتمل بعد. الأجزاء الحالية في ذاكرة الصفحة، وليست محفوظة في IndexedDB.
- لم تُنفذ بعد اختبارات أحجام الملفات الكبيرة أو التوافق الواسع مع أجهزة التلفاز.
- يلزم تدقيق أمني واختبارات ضغط قبل الاستخدام الإنتاجي. رسائل الإشارة فقط تمر عبر Durable Objects؛ الملفات تنتقل نظرياً عبر DataChannel بين الطرفين.
