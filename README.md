# نقل مباشر — Direct Transfer

موقع ويب لنقل الملفات مباشرة بين الأجهزة باستخدام WebRTC DataChannel. لا يتطلب حساباً أو تثبيت تطبيق.

## البنية
- `index.html`, `styles.css`, `app.js`: واجهة ويب عربية/إنجليزية، متوافقة مع اللمس والفأرة وريموت التلفاز.
- `worker/src/index.js`: Cloudflare Worker + Durable Object لتنسيق الجلسات وWebSocket signaling فقط.
- `worker/wrangler.toml`: إعداد النشر وربط Durable Objects.

## التشغيل المحلي للواجهة
شغّل خادماً ثابتاً من جذر المستودع، مثلاً:
`python3 -m http.server 8080`
افتح `http://localhost:8080`. تتطلب ميزات WebRTC وService Worker سياقاً آمناً (HTTPS أو localhost).

## نشر الواجهة
يمكن نشر الجذر على Cloudflare Pages أو GitHub Pages. لا تنشر Worker ضمن Pages كملفات ثابتة؛ انشره منفصلاً باستخدام Wrangler.

## نشر signaling على Cloudflare
1. ثبّت Wrangler: `npm install -g wrangler`
2. سجّل الدخول: `wrangler login`
3. من مجلد `worker`: `wrangler deploy`
4. انسخ عنوان Worker المنشور وضعه في إعدادات الواجهة (زر الإعدادات أو ثابت `SIGNALING_URL` في `app.js`).
5. عند استخدام نطاق مخصص، اجعل الواجهة والـ Worker على HTTPS.

## آلية الاتصال
1. المرسل ينشئ جلسة مؤقتة ويحصل على رابط يحتوي معرّف الجلسة وسرّ المرسل.
2. المستقبل يفتح الرابط ويطلب الانضمام.
3. يظهر طلب الاقتران للمرسل، ولا يبدأ WebRTC قبل موافقته.
4. يتبادل الطرفان SDP وICE عبر Durable Object؛ لا تمر الملفات عبره.
5. يتم النقل عبر WebRTC DataChannel مباشرةً. إعداد ICE يحتوي STUN فقط، ولا يوجد TURN.

## الخصوصية والقيود
- لا تُرفع الملفات إلى Worker ولا تخزن مركزياً.
- يحتفظ المتصفح بسجل النقل وحالة الأجزاء محلياً عبر IndexedDB.
- الاستكمال يتطلب بقاء الملف الأصلي لدى المرسل وبقاء بيانات المتصفح والجلسة متاحة.
- لا يوجد TURN أو relay للملفات. قد تفشل الاتصالات على بعض شبكات NAT أو الجدران النارية.
- رابط الجلسة سرّي؛ شاركه مع المستقبل المقصود فقط. يستطيع المرسل إلغاء الجلسة.
- هذه نسخة أولية قابلة للتشغيل، ويجب اختبارها على الشبكات والأجهزة المستهدفة قبل الاعتماد الإنتاجي.

## اختبارات سريعة
- افتح الموقع في جهازين مختلفين عبر HTTPS.
- أنشئ جلسة، وانسخ الرابط إلى الجهاز الثاني.
- اقبل الطلب من الجهاز المرسل، ثم اختبر إرسال ملف صغير وكبير.
- اختبر الرفض، وإلغاء الجلسة، وإرسال أكثر من ملف، والاتصال بعدة مستقبلين.
