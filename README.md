# وصلة — نقل الملفات مباشرة

موقع ويب لنقل الملفات بين المتصفحات عبر WebRTC DataChannel.

## الاستخدام عبر الإنترنت
1. افتح الموقع على الجهازين.
2. أنشئ جلسة إرسال وشارك الرابط أو QR.
3. افتح الرابط على الجهاز المستقبل.
4. اختر الملفات وابدأ الإرسال.

## الاقتران ثم النقل المحلي دون إنترنت
1. يجب أن يكون الجهازان متصلين بالإنترنت مؤقتًا، ويفضل أن يكونا على شبكة Wi-Fi المحلية نفسها.
2. افتح تبويب **الاتصال المحلي** على الجهاز الأول واضغط **إنشاء اتصال وعرض QR**.
3. يمسح الجهاز الثاني الرمز بالكاميرا (أو يدخل رابط/معرّف الاقتران يدويًا) ويرسل طلب الاقتران.
4. يوافق الجهاز الأول على الطلب.
5. يتبادل المتصفحان معلومات WebRTC عبر PeerJS signaling، ثم ينشئان DataChannel مباشرًا.
6. يتحقق التطبيق من أن مسار ICE المختار Host-to-Host وأن عناوين الطرفين محلية/خاصة أو mDNS. إذا لم يستطع إثبات ذلك، يغلق الاتصال ولا يسمح بإرسال الملفات عبر مسار إنترنت.
7. بعد ظهور حالة **اتصال محلي مباشر جاهز** على الجهازين، يمكن فصل اتصال الإنترنت مع إبقاء شبكة Wi-Fi المحلية فعالة. يستمر نقل الملفات عبر DataChannel المباشر ما دامت صفحة المتصفح والاتصال مفتوحين.

## ما الذي يمر عبر الإنترنت؟
- أثناء الاقتران: اتصال PeerJS signaling لتبادل معرّفات الاتصال ومعلومات WebRTC، وقد تُستخدم خوادم STUN لجمع المرشحين.
- بعد نجاح الاتصال المحلي: محتوى الملفات ينتقل مباشرة بين الجهازين عبر WebRTC DataChannel، ولا يمر عبر PeerJS أو خادم الإشارات.
- فصل الإنترنت قبل اكتمال الاقتران أو قبل ظهور تأكيد المسار المحلي سيمنع إنشاء الاتصال.

## ملاحظات وحدود مهمة
- يجب تحميل الموقع وموارده قبل فصل الإنترنت. تعمل الصفحة المحفوظة عبر Service Worker عند توفر نسخة مخزنة، لكن إعادة التحميل دون اتصال قد تتأثر إذا لم تكن مكتبات الطرف الثالث قد حُمّلت/خُزّنت.
- مسح QR بالكاميرا يعتمد على دعم المتصفح لواجهة BarcodeDetector؛ يوجد إدخال يدوي بديل لمعرّف الاقتران.
- بعض متصفحات التلفاز لا توفر كاميرا أو BarcodeDetector؛ في هذه الحالة استخدم إدخال الرابط/المعرّف يدويًا أو امسح الرمز بهاتف آخر حسب إمكانات الجهاز.
- بعض المتصفحات تخفي عناوين LAN أو لا تعرض تفاصيل المرشح المختار. في هذه الحالات قد يرفض وصلة الاتصال احترازيًا بدل الادعاء بأن النقل محلي.
- لا يمكن ضمان اتصال محلي بين شبكتين مختلفتين أو إذا كانت نقطة الوصول تعزل الأجهزة (AP/client isolation).
- إغلاق الصفحة أو إيقاف المتصفح أو إطفاء Wi-Fi يقطع النقل.
- نقل الملفات يستخدم دفعات 64KB ومراقبة مخزن الإرسال. الاستقبال يكتب تدريجيًا إلى File System Access API أو OPFS، مع IndexedDB كخيار بديل محدود بسعة المتصفح.

## الملفات
- `index.html`: الواجهة.
- `styles.css`: التصميم ودعم الشاشات والريموت.
- `app.js`: الاقتران، التحقق من مسار LAN، ونقل الملفات.
- `sw.js`: التخزين المؤقت لملفات الموقع.
